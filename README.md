# Tasks Enhancer

一个围绕 Obsidian 任务的增强插件，包含三大功能：**排序**、**转为任务**、**一键整理归档**。

- **排序**：按完成时间整理当前笔记里的任务，未完成任务置顶/置底，支持非任务内容置顶、分组标题、选区排序、自动排序。
- **转为任务**：选中多行文本，一键在每行加上任务前缀（默认 `- [ ] `）。
- **一键整理**：把散落在各处笔记里的任务归档到 `Tasks` 目录下的日期文件（如 `Tasks/2026-10-09.md`），已完成的任务按完成日期归位，未完成的任务顺延到下一天。

配合 `tasks-datetime` / Tasks 插件使用：勾选任务后会自动写入 `✅ 2026-10-08 20:56:59`，本插件负责把这些任务整理成有序列表与归档文件。

> 原名 Task Sorter。升级为 Tasks Enhancer 后，目录与插件 id 变更为 `Tasks-Enhancer` / `tasks-enhancer`，旧的 `Task-Sorter` 目录已移除；设置沿用原有 `data.json`，新增项自动取默认值。

## 安装与启用

1. 本目录已放在 `.obsidian/plugins/Tasks-Enhancer/`（`manifest.json` + `main.js`）。
2. Obsidian：设置 → 第三方插件 → 关闭「限制模式」→ 刷新 → 启用 **Tasks Enhancer**。
3. 免构建：修改 `main.js` 后重启 Obsidian（或「重新载入插件」）即生效，不需要 npm。

## 入口

左侧只有一个图标（清单 + 勾选 = 任务增强）。**点击它弹出功能菜单**，每一项都带自己的图标：

| 图标 | 含义 | 菜单项 |
| --- | --- | --- |
| 上下箭头 | 排序 | 一键排序：按设置整理当前文件 |
| 归档箱 | 整理归档 | 一键整理：归档到 Tasks 日期文件 |
| 清单 + 加号 | 转为任务 | 选中的行转为任务 |
| 向上箭头 | 非任务内容置顶 | 非任务内容置顶并排序 |
| 齿轮 | 设置 | 打开 Tasks Enhancer 设置 |

命令面板、编辑器右键菜单、文件右键菜单里的各项也使用同一套图标。

其余入口：

- **命令面板**（`Ctrl+P` 搜索 `Tasks Enhancer`）
  - 排序当前文件（按设置）
  - 未完成置顶/置底 · 完成时间从早到晚 / 从晚到早（4 条）
  - 排序选中的任务区域
  - 非任务内容置顶并排序
  - 切换排序范围（连续块 / 整文件）
  - 把选中的行转为任务
  - 一键整理：把任务归档到 Tasks 日期文件
  - 清理当前文件的空任务行
  - 打开 Tasks Enhancer 设置
- **编辑器右键菜单**：按设置排序 / 排序选中区域 / 选中的行转为任务 / 非任务内容置顶并排序 / 清理空任务行
- **文件列表右键菜单**：排序此文件 / 非任务内容置顶并排序 / 整理此文件的任务 / 清理空任务行
- **自动排序**：可在设置里选择「文件保存时」或「编辑空闲时」

## 功能一：排序

把未完成任务集中置顶或置底，已完成任务（含取消）按完成时间或其他字段排序。

### 设置项

#### 排序结果

| 设置 | 说明 | 默认 |
| --- | --- | --- |
| 未完成任务位置 | 待办集中在任务区最上面或最下面 | 置顶 |
| 未完成任务排序依据 | 保持原顺序 / 截止日期 / 创建时间 / 优先级（高→低） | 保持原顺序 |
| 已完成任务排序依据 | 完成时间 / 截止日期 / 创建时间，各含两个方向 | 完成时间：早→晚 |
| 排序范围 | **连续块**：只在相邻任务行内部排序，空行与正文是分隔；**整文件**：全文任务统一重排 | 连续块 |
| 取消任务单独分组 | `❌` / `[-]` 任务单独成组，排在已完成之后 | 关闭 |
| 没有时间的任务视为最新 | 关了当最早，开了当最新 | 关闭 |

#### 非任务内容

| 设置 | 说明 | 默认 |
| --- | --- | --- |
| 非任务内容位置 | **保持原位**：标题、正文、代码块就地保留；**集中置顶**：非任务内容整体移到顶部、压缩多余空行，任务统一排下方（YAML 属性区始终在最前） | 保持原位 |

#### 分组标题

| 设置 | 说明 | 默认 |
| --- | --- | --- |
| 插入分组标题 | 不插入 / 整文件：任务区统一插入 / 连续块：每段分别插入 | 不插入 |
| 待办标题 | 未完成组的标题文字，留空则不插 | `## 待办` |
| 已完成标题 | 已完成组的标题文字，留空则不插 | `## 已完成` |
| 已取消标题 | 取消组的标题文字（需开启「取消任务单独分组」） | `## 已取消` |

插入是幂等的：先删除上次插入的同名标题再重新插入，重复排序不会堆积标题，空组不插标题。

## 功能二：转为任务

选中若干行后执行，每行会加上任务前缀（保留原有缩进）。

| 设置 | 说明 | 默认 |
| --- | --- | --- |
| 任务前缀 | 加在每行开头的文本，需含状态符号 | `- [ ] ` |
| 跳过空行 | 选区里的空行不加前缀 | 开启 |
| 跳过已经是任务的行 | 已带复选框的行保持不动 | 开启 |
| 跳过代码块内的行 | ``` 与 ~~~ 围栏内的行不转换 | 开启 |

写入走编辑器事务，支持 `Ctrl+Z` 撤销。

## 功能三：一键整理（归档）

### 归档规则

假设整理基准日是 **2026-10-09**：

- 已完成 / 已取消任务：按 `✅` / `❌` 后的**日期**写入对应文件
  - `✅ 2026-10-06` → `Tasks/2026-10-06.md`
  - `✅ 2026-10-08 20:56:59` → `Tasks/2026-10-08.md`
- 文件内部顺序：**没有小时分钟的统一排在最上面**，有小时分钟的按时间升序
- 未完成任务：默认写入 `Tasks/2026-10-10.md`（基准日 + 1 天），也可改为写入你指定的固定文件或留在原文件
- 已勾选但没有时间记录的任务：默认归到基准日文件 `Tasks/2026-10-09.md`（也可设为留在原文件）
- **不去重**：默认即使内容完全相同也全部照常移动（例如三天都写了"洗碗"，三条都会各自归档）。需要去重可在设置里开启
- **空任务行直接删除**：去掉时间戳、日期字段、优先级符号、内联字段后没有任何正文的行（例如 `- [ ]`、`- [x] ✅ 2026-10-09 00:49:20`）不会写入归档文件，而是直接从源文件删除；移动与复制模式都会清理
  - 不会被误删的例子：`- [x] 烧水 🔁 every day ✅ 2026-02-01`、`- [x] ![](图片) ✅ 2026-10-03` 都有正文
- 目标文件已存在时追加合并并整体排序，不覆盖原有内容

示例：整理 `diary/2026-10-08.md` 与 `dz.md` 后，`dz.md` 里 10-06、10-07 完成的任务分别进 `Tasks/2026-10-06.md`、`Tasks/2026-10-07.md`，两个文件里的未完成任务统一进 `Tasks/2026-10-10.md`，原文件中的这些行被移除。

### 设置项

#### 任务整理

| 设置 | 说明 | 默认 |
| --- | --- | --- |
| 归档目录 | 日期文件所在目录（相对仓库根），不存在时自动创建 | `Tasks` |
| 日期文件名格式 | 支持 `YYYY` / `MM` / `DD` 占位符 | `YYYY-MM-DD` |
| 整理范围 | 当前文件 / 指定文件夹 / 整个仓库 | 当前文件 |
| 来源文件夹 | 「指定文件夹」时的路径，留空为仓库根目录 | `diary` |
| 包含子文件夹 | 整理来源文件夹时连同子文件夹 | 开启 |
| 完成日期起始 | 只整理完成日期不早于该日期的任务，留空不限 | 空 |
| 完成日期截止 | 只整理完成日期不晚于该日期的任务，留空不限 | 空 |
| 整理基准日 | 「基准日 + 1 天」用到的日期，留空表示今天 | 空（今天） |
| 未完成任务去向 | 基准日 + 1 天的日期文件 / 指定的固定文件 / 留在原文件 | 基准日 + 1 天 |
| 未完成任务的输出文件 | 上一项选「指定的固定文件」时填写，例如 `Tasks/待办`；纯固定路径，不做日期替换，自动补 `.md`，留空则回退到基准日 + 1 天 | 空 |
| 整理时删除空任务行 | 没有正文的任务行直接从源文件删除、不写入归档文件（移动与复制模式都清理） | 开启 |
| 整理方式 | **移动**：原文件中的这些任务行被移除；**复制**：原文件保留 | 移动 |
| 无完成时间的已完成任务 | 归到基准日文件 / 留在原文件 | 归到基准日文件 |
| 跳过重复任务 | 默认关闭（相同内容也全部移动）；开启后目标文件里已有的同内容任务不再重复写入 | 关闭 |
| 归档文件插入分组标题 | 整理后的日期文件里自动加标题 | 关闭 |
| 整理前弹确认框 | 展示将影响的文件与任务数量，取消则不写入任何文件 | 开启 |
| 删除整理后变空的文件 | 默认关闭；开启后源文件被移空时会被删除 | 关闭 |

归档目录内的文件可以被再次整理。例如你在 `Tasks/待办.md` 里勾选完任务后再整理，已完成的任务会回到各自的日期文件；如果某条任务的目标文件正是它当前所在的文件，整理时会跳过它（不会把内容重复搬进自己）。若想恢复"完全不扫描归档目录"，可开启设置项「整理时排除归档目录」。

## 触发方式与其他

| 设置 | 说明 | 默认 |
| --- | --- | --- |
| 只排序选中的区域 | 有选区时只重排选区内任务，走编辑器事务可撤销 | 开启 |
| 自动排序 | 关闭 / 文件保存时 / 编辑空闲时 | 关闭 |
| 自动排序的文件夹 | 只对该目录自动排序，留空为全部 | 空 |
| 空闲秒数 | 「编辑空闲时」等待秒数，最小 2 | 10 |
| 显示操作提示 | 排序/整理完成后显示统计信息 | 开启 |

## 识别规则

- 任务行：行首的 `- [x]`、`* [ ]`、`1. [/]` 等（正文里出现 `- [ ]` 不会被误判）。
- 状态：`[x]` 已完成；`[-]` 取消（默认与已完成一起按时间排）；`[ ]`、`[/]` 未完成。
- 完成 / 取消时间（按优先级）：
  1. `✅` `❌` `✔` `✓` 后的日期时间：`2026-10-08`、`2026-10-08 20:56`、`2026-10-08 20:56:59`、`2026-10-08T20:56:59`
  2. 内联字段：`[done:: 2026-10-08]`、`[完成时间:: …]`
  3. 兜底：去掉 `created::`、`due::` 等字段后取行内最后一个日期
- 其他排序字段：`📅` / `[due:: ]` 截止，`➕` / `[created:: ]` 创建，`🛫` 开始，`⏳` 计划，优先级 `⏫` 高 / `🔼` 中 / `🔽` 低。

## 安全边界

- 排序只移动任务行，**不会改动**标题、正文、表格、YAML frontmatter 与代码块内容（``` / ~~~ 内部完全忽略，空行压缩也不会进入代码块）。
- 缩进的子任务/补充说明跟随父任务整体移动。
- 相同排序值的任务保持原有相对顺序，结果可重复。
- 内容没有变化时不写入文件；整文件写入走 `vault.process`，选区写入走 `editor.replaceRange`，都支持 `Ctrl+Z`。
- 自动排序带自我写入守卫（2 秒内忽略自己触发的变更），不会造成写入循环。
- 一键整理执行前先做一次不落盘的预演，并用确认框列出：涉及源文件数、任务条数、每个目标文件的写入条数（新建 / 追加合并）、整理方式；**取消则一个文件都不写**。
- 默认**不会删除任何文件**；只有在你主动开启「删除整理后变空的文件」时，源文件被移成空文件才会被删除，且确认框会额外提示。

建议第一次使用先复制几份笔记试跑，确认效果后再用于正式文件。
